# Better Trajectory 设计语言

> 目标：一套自顶向下的 UI/UX 规范，先定「手感」，再定组件。实现必须能逐条对照本文，而不是边写边发挥。

## 1. 手感主张：仪表感（instrument-grade）

**一句话**：像调音台，不像笔记本。密度高、反馈短、层级靠线不靠影、动效只做连续性。

三个静态同样「Soft SaaS」的产品，手感差在节奏：

| 产品 | 手感 | 我们不学的地方 |
|---|---|---|
| Linear | 快、硬、键盘优先，80–120ms，强对比 | 它的品牌色与渐变 |
| Notion | 软、纸感、200ms+，低对比、留白多 | 它的慢与宽松 |
| Kite | 暗、密、发光强调 | 它的装饰性辉光 |

**我们的三条硬规则**

1. **动效 ≤ 220ms，且只服务于「东西从哪来、到哪去」**；数据变化、过滤结果、计数一律不动画。
2. **层级用 1px 发丝线与底色差表达，不用阴影**（浮层除外）；hover 不改变布局尺寸。
3. **键盘路径永远是完整的一等路径**，鼠标只是加速器。

由此得到的辨识度：单行瀑布 + 等宽锚点 + 语义色（只有错误/运行中/成功三色）+ 无弹跳。

## 2. 设计系统

### 2.1 色彩

只做语义色，不做品牌装饰色。全部映射到宿主 `--dsw-alias-*`，插件不写死十六进制（暗色自动继承）。

| Token | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| `--bt-surface` | `#ffffff` | `#1b1c1e` | 页面/列表底 |
| `--bt-surface-2` | `#f6f7f9` | `#232427` | hover、输入框、chip 底 |
| `--bt-surface-3` | `#eef0f3` | `#2b2d31` | 选中底、按下态 |
| `--bt-line` | `#e6e8eb` | `#33363b` | 发丝线（1px，占位不占重） |
| `--bt-line-soft` | `#f0f2f4` | `#2a2c30` | 缩进导轨、分组缝 |
| `--bt-text` | `#1c2128` | `#e6e8ea` | 主文本、名称 |
| `--bt-text-2` | `#5b6470` | `#a7adb6` | 次级文本、参数 |
| `--bt-text-3` | `#9aa1ab` | `#6f757d` | 时间、单位、占位 |
| `--bt-accent` | `#2563eb` | `#6b9bff` | 选中轨、链接、焦点环 |
| `--bt-error` | `#d92d20` | `#ff6b5e` | 失败状态、错误徽章 |

规则：状态永不只靠颜色——必须同时有文字或形状（点/徽章/左轨）；错误红只用于「失败」，不用于普通强调。

### 2.2 排版

| 角色 | 字号/行高 | 字重 | 字体 | 用途 |
|---|---|---|---|---|
| 名称 | 11.5 / 1.2 | 500 | mono | 工具名、assistant、user |
| 行主文本 | 12 / 1.4 | 400 | sans | 消息摘要、详情正文 |
| 参数/JSON | 11.5 / 1.65 | 400 | mono | 右栏树、参数 |
| 时间/毫秒 | 10.5 / 1 | 400 | mono tabular | 时间槽、耗时 |
| 标签（kind tag） | 10 / 16px | 650 | sans | 助手 / 工具 / 用户 / 上下文（对齐原生 `kindTag`） |
| 徽章 | 9.5 / 17px | 500 | mono | error / running |
| 面板标题 | 13 / 1.3 | 600 | sans | 右栏标题 |

字距：mono `0.01em`；全大写标签 `0.04em`。数字一律 `font-variant-numeric: tabular-nums`。

### 2.3 间距与网格

4px 基准：`2 4 6 8 12 16 24`。

行网格（固定，不随内容跳动）：

```
[ 84 时间 ][8][ 12 折叠 ][10 状态点 ][8][ 名称 自适应 ][6 徽章 ][8 子文本 flex ][12][ 64 耗时条 ][8][ 52 毫秒 ]
```

行高恒定：行线 **28px** 加 1px 分隔线，`tr` 永远 **30px**（与原生表一致，虚拟滚动的 `CONTENT_ROW_HEIGHT` 也是 30）。
任何内容都不能改变行高——折叠展开、长消息、多行摘要一律单行截断加省略号。这条是硬约束：
行高一旦随内容变化，虚拟滚动的位置就会漂，树连线也会跟着错。

树的几何只有一个来源，全部由两个数推出来（`--bt-step: 26px`、`--bt-dot: 12px`）：

| 量 | 定义 |
|---|---|
| 本行轴心 `--bt-axis` | `26L + 12`，即折叠点圆心 |
| 内容缩进 | `26L` |
| elbow（横向） | 父行圆心 `axis - 26` → 有圆点时圆点外缘 `axis - 4`，无圆点时标签槽 `axis + 20` |
| drop（纵向） | 本行圆心 `axis`，从圆点下方到行底 |
| rail(a) | 祖先层 a 的圆心 `26a + 12` |

纵向也只有一个来源：`--bt-marker-y = 行首行内距 + 14px`，折叠控件盒高正好一行（28px），
所以圆点、elbow、drop 在任何行高下都共线。此前 elbow 写死 `top: 50%`，而消息行是顶对齐
且带 5px 内距，多行消息上连线会比圆点低 10px。

折叠控件外形 8px 圆环，命中区 24×28 的方块（去掉 `border-radius` 才不会把点击裁成圆）。

### 2.4 形态与层级

| 元素 | 圆角 | 说明 |
|---|---|---|
| 标签 / 徽章 | 4px | 与原生 `--dsw-radius-xs` 一致；标签 19px 高、5px 内距 |
| chip / 按钮 / 输入 | 4–6px | 统一 4 为主，输入 6 |
| 面板 / 浮层 | 8px | 浮层才用 8 |
| 选中轨 | 2px 宽 | 左缘，不圆角 |

阴影只有两处：下拉/浮层 `0 8px 24px rgba(16,24,40,.10)`，拖拽幽灵 `0 2px 8px rgba(16,24,40,.12)`。其余靠 1px 线。

层级：`--z-sticky:10`（查询条）、`--z-popover:30`、`--z-drag:40`。

### 2.5 图标与符号

12px、1.5 stroke、`currentColor`。只保留三类：折叠三角、状态点、复制。**能用布局/颜色表达的，不加图标。**

## 3. 布局

```
┌ 工具条 行1 28：← → · 视图开关 · 搜索框 · ⓘ ─────────────────┐
│        行2 22：条数/调用/错误/时长（左）· 筛选 chip（右）      │
├ 活动条 28（细柱状，无图例，可框选时间范围）────────────────┤
├ 树 flex ───────────────────────────┬ 详情 520（clamp 420–720）┤
│ 行 28 × N                          │ 头部 36 / chips 28 /      │
│ 分组缝 10                           │ meta 22 / tabs 30 / body  │
└────────────────────────────────────┴──────────────────────────┘
```

- 查询条固定 40px；输入聚焦时高度不变（建议菜单浮层覆盖，不推挤）。
- 搜索框最宽 560px（够读一条中等长度的查询，再宽只是留白）；语法按钮紧跟其右。
- 统计行（第二行）左边是「标签 + 数值」：标签统一 2 字（记录 / 调用 / 错误 / 时长）、灰色 10px，数值等宽 11px、tabular-nums，所以四列天然对齐；错误数在非 0 时整列变红。
- 筛选区贴右，并在其左侧有一条 1px 发丝线——「窗口里有多少」和「筛出了什么」是两个问题，靠线分开，不靠间距猜。
- 建议菜单：左侧灰字是**查询语法本身**（`tool:` `status:` `turn:` `ms:` `type:`），保持英文、等宽、不本地化；右侧是值，再右是计数。
  - 键盘：`↑↓` 移动预选（滚出可视区自动跟随）、`Tab` / `Enter` 采纳、`Esc` 关闭。
  - 预选行只用**灰色**：6% 底 + 1px 轻阴影 + label 加粗。不要左侧色轨——`--bt-accent` 在本主题解析成近黑（`#0f1115`），那条 2px 会变成一道黑边；也不要用 `--dsw-alias-bg-layer-2`（解析成 `#fff`，等于没有预选态）。
  - 输入字段前缀（`ty`、`st`）先列该字段的值；输入值是值内过滤（`b` → `bash` / `glob`）。
- 查询条**右端常驻总统计**：`N 条记录 · N 次调用 · N 个错误 · 窗口总时长`，等宽数字、10–11px，与查询用一条发丝线隔开。查询生效时数字降为次级色，命中数在 chip 行（`命中 N · M 个被过滤 · 显示全部`），两处分工不重复。
- 活动条 28px：去掉原生图例（输入/模型/思考/工具），只用颜色深浅+错误红点提示分布；hover 显示该区间计数。
- 详情默认 520px，拖动范围 420–720，吸附点 420 / 520 / 640。
- 视口 <1280 时详情默认 460；<1024 时详情变覆盖层（从右滑入 200ms），不挤压树。

## 5. 动效系统

| Token | 值 | 用途 |
|---|---|---|
| `--bt-dur-1` | 60ms | 按下、颜色微变 |
| `--bt-dur-2` | 90ms | hover、chip 出现 |
| `--bt-dur-3` | 120ms | 行删/增、折叠开始 |
| `--bt-dur-4` | 160ms | 面板、tab、toast |
| `--bt-dur-5` | 220ms | 拖拽吸附、覆盖层 |
| `--bt-ease-out` | `cubic-bezier(.25,1,.5,1)` | 进入 |
| `--bt-ease-std` | `cubic-bezier(.2,0,0,1)` | 位移/尺寸 |
| `--bt-ease-exit` | `cubic-bezier(.4,0,1,1)` | 退出 |

**禁止**：spring、回弹、无限循环动画（运行中 pulse 与骨架除外）、对数字做滚动动画。

| 交互 | 动效 |
|---|---|
| hover 行 | 背景 90ms；不做位移、不做缩放 |
| 选中 | 左轨立即出现（0ms），底色 90ms |
| 折叠/展开 | 高度 120ms + 内容 opacity 80ms；三角旋转 90ms |
| 过滤生效 | 行集合瞬时替换；列表整体 opacity 120ms 防闪 |
| 详情打开 | 宽度 160ms + 内容 opacity 120ms（覆盖层模式为 translateX 200ms） |
| 拖拽分隔 | 1:1 跟手；越界 0.85 阻尼；松手 180ms 吸附 |
| toast | translateY 8px + opacity，160ms 进入；退出 120ms |
| 骨架→内容 | 120ms 交叉淡入，不闪白 |
| 焦点环 | 立即出现，不做动画 |

`prefers-reduced-motion: reduce` 时全部 0ms，骨架改静态。

## 6. 交互体验层

### 6.1 状态机

**查询**：`idle → typing（建议打开）→ committed（chip + 过滤）`；非法 token → `invalid`（输入框下 2px 琥珀线，Enter 时在建议区显示一行原因，不弹 toast）。

**过滤**：无 token = 原样；有 token = 只裁工具行；过滤态下禁用「加载更早」；清空 → 回到原样并给撤销 toast。

**选中**：`none → row（列表焦点）→ detail（右栏打开）`；Esc 从 detail → row，再 Esc → none；`focusRequest` 从对话跳入时：滚动 120ms + 选中 + 600ms accent 淡出高亮。

**加载**：首次 >200ms 显示骨架；更早历史用行内 24px 占位；流式行只加 1px 光标，不改变行高。

### 6.1.0 导轨：两端对称

- 导轨（活动条）左右两端是**同一套机制**，只有动作不同：左端 `取下一页历史`，右端 `把已加载的更新记录显示出来`（没有更晚的页可取，所以不叫加载）。
- 共用：20px 触发区、8px 迟滞（离开 28px 才复位）、`按住不放就继续`的链式推进、4px 呼吸点。判据同样只有两条：没有在飞的请求 + 上一次推进确实带来了变化；**任何一端都不加计时器**。
- 迟滞与判定的实现在一个 `parkAtEdge(clientX)` 里，按下和移动都走它；左端清理不依赖 `hasEarlierRecords`（取完历史后该标志为假，否则停靠状态会永久卡住）。
- 右端点只在「缩放后右侧还有记录」时出现；已在最新端时没有点、也没有动作——这就是「一般不需要加载」。
- 悬停时**一条虚线光标**贯穿导轨（1px 虚线，3/3 间隔，accent 62%），不再用 2px 实心条（会被误读成选区）。
- 光标卡片（对齐 Logfire 的 Cursor point 卡）：`光标` / 有柱时加 `区间`（+ `耗时` 取该记录真实耗时）/ `记录 N 条`。
  - **不打印「可见窗口」**：它就是整条导轨本身，未缩放时永远是 `0 – 全长`，属于不变量，写出来只是噪声。
  - **计数跟着选区走**：有选区（拖拽中或已提交）时标签变 `选中`、数字是落在选区里的记录数；没有选区时是可视窗口内的记录数。
  - 不放按键说明（单击/拖拽/滚轮）：那是常驻提示，不是这条记录的信息。
  - 序号模式（默认）横轴是记录序号，值写成 `#53`；`时长` 模式下是压缩后的偏移，写成 `2.5s`；真实时间模式写成 `10:37:45.120`。
  - 滑到空白处时**没有卡片头**——头里重复一遍光标值只像 bug。

### 6.1.0 导航与历史

- **历史自动加载**：不再有「加载更早」按钮。列表滚到顶部（阈值内）、时间轴**按下或拖拽到左缘 20px 内**即自动取下一页；取完把滚动位置钉回原处，左侧只留一个 4px 呼吸点表示「还有更早」。
  - 边界判定用相对容差（`fullDuration × 1e-6`）：平移会把视窗夹到 `model.start`，严格相等永远不成立。
  - 左缘判定要用 **track 的矩形**，不能用事件目标：plot 从标签列开始，比 track 靠左 40px，按 track 算才等于「贴住最左」。
  - 手势触发与边界标记用**两个守卫**：标记每次 `model.start` 只加载一次（否则会一路分页到底）；手势用「离开边缘才算新一次会话」的迟滞（`edgeLoadDone`，离开 >28px 复位），不用计时器。用计时器时，悬停刚加载完紧接着拖动要等满冷却，感觉拖动比悬停慢。
  - 轨道上的**滚轮 = 缩放**：向上滚放大、向下滚缩小；已经缩到全量（100%）时继续向下滚就取下一页历史，也就是「展开不了就加载」。
  - **没有时间冷却**。加载只受两个事实约束：① 没有在飞的请求（`loadEarlier` 在加载中为 `undefined`）；② 上一页确实带来了新 span。计时器只会人为制造空转等待。
  - **停在边缘会连续加载**：指针停在左缘 20px 内时，每落一页就接着取下一页，直到没有更多（判据是 span 数不再增长，不看 `model.start`——只放宽节点上限的加载不会改变它）；指针离开 28px 即停。
  - **边界标记不会自己翻页**：只有「进入最早边界」的那一次触发一页，离开后重新武装；否则每次加载都会让 `model.start` 左移，守不住就一路翻到底。
- **筛选作用于所有记录类型**：工具 / 子调用 / 助手 / 用户 / 上下文 / 压缩点都过同一份判据（`matchesCell`），不命中就隐藏；否则 `status:error` 会留下满屏助手消息，反而看不出筛掉了什么。`tool:` 只可能命中调用，`status:` / `code:` / `ms:` 对消息使用各自的真实字段。
- **没有「本组 N 条被过滤」行**：过滤后每个组都掉一条时，那行比内容还密；被过滤的总数只在 chip 行说一次。
- **前进 / 后退**：工具栏最左 `← →`，记录「打开的记录」和「提交的时间轴选区」两类步骤，上限 50 条（超出丢弃最早的）；一次拖拽只记一步（`onRangeChange` 只在提交时触发），输入框内不触发快捷键 `Alt+←` / `Alt+→`。
- **类型筛选**：`type:call|message|user|system|context|compacted`，支持 `|` 与 `-`；建议菜单有 `type:` 组。`call` = 工具 + 子调用，`assistant` 是 `message` 的别名。
- 工具栏右侧不再放任何「快捷筛选」按钮：`错误 / 运行中 / 慢 / 平铺` 已删除，筛选只走查询条 token（`status:error`、`ms:>1000` 等）。

### 6.1.0a 查询语法（唯一事实来源）

一条查询 = 空格分隔的若干 token，**全部 AND**。每个 token 的形式是 `字段:值` 或裸词。

| token | 值 | 匹配谁 | 说明 |
|---|---|---|---|
| `tool:bash` | 名字 | 只有 `tool` / `subtool` | 等值（忽略大小写）；支持 `*` 通配与 `\|` 并列：`tool:todo*`、`tool:bash\|read` |
| `type:message` | 类型别名 | 所有记录 | `call` / `tool` / `subtool` / `message` / `assistant` / `user` / `system` / `context` / `compacted`；`kind:` 是等价别名。**不是日志级别**（级别用 `status:`） |
| `status:error` | ok / error / running | 所有记录 | `\|` 并列；中断（interrupted）算 error |
| `turn:12` | 数字或 `A-B` | 所有记录 | 区间闭区间 |
| `ms:>1000` | `>` `<` `>=` `<=` 或 `A-B` | 有耗时的记录 | 消息用生成耗时；没有耗时的记录不匹配 |
| `code:401` | 数字或 `*` | 只有调用 | 错误码等值；`code:*` = 有错误码 |
| `args:path` | 文本 | 输入侧 | 工具参数 / 用户与上下文正文 |
| `result:error` | 文本 | 输出侧 | 工具结果 / 助手正文 |
| `error:timeout` | 文本 | 失败记录 | 非失败记录没有这段文本，所以不匹配 |
| `text:foo` / `foo` | 文本 | 全字段 | 名称 + 参数 + 结果 + 正文 |
| `-token` | — | 取反 | 对任何 token 生效，包括裸词（`-success` 排除含 success 的记录） |
| `"git push"` | 短语 | 同上 | 引号保留空格；写回查询时自动补引号 |

规则与边界：

- **AND 优先**：没有括号、没有 OR 组合（`|` 只在单个值内并列）。多字段互相收窄，够用且不可误读。
- **未知字段回退成文本**：`http://x` 里的 `http:` 不是字段，整段当一个搜索词（`-http://x` 同样取反）。
- **非法值不参与过滤**：`ms:abc` 保留成 chip 并标黄，过滤时忽略，不阻断输入。
- **作用域只看「输入侧 / 输出侧」**，不逐字段细分（`args:` 不区分是哪个参数），因为调试时你要的是「这条记录里有没有提到」。
- 不做：正则、布尔括号、`seq:` / 时间戳范围（时间轴选框已经覆盖时间维度）。

### 6.1.0b 折叠的唯一实现

| 折叠对象 | 一行代表什么 | 行上必须有的东西 |
|---|---|---|
| 回合 | 回合的第一条**内容**记录（非 system / 非 request-only） | `第 N 轮` 折叠控件 + `N 步 · N 工具 · 耗时` chips |
| 助手消息 | 消息本身 | 折叠控件 + `N 工具 · 耗时` chips（工具行收起） |
| 工具 | 工具本身 | 折叠控件 + `N 工具` chips（子调用收起） |

- 折叠行同时是 `turnStart` 与 `turnEnd`：它就是这一轮的起止，否则没有可点的控件（曾经因为锚在 system 行上，`turnStart` 恒假而无法展开）。
- 「N 步」= 有请求的分组数，不是分组总数；前导的 system/user/context 分组不算一步。
- chips 就是摘要，不再另插一行 `collapsedSummary`（原生那套两行折叠已删）。

### 6.1.1 右栏信息架构（对齐 Logfire live view）

一份数据只有一个入口。页签只切换**表示法**，不切换数据：

| 记录 | 页签 | 概述内容 |
|---|---|---|
| 工具 / 子调用 | 概述 · 计时 · 原始 | 属性一行（状态 · 耗时 · ID，ID 可复制）+ 可折叠 `参数` / `结果` / `Schema` |
| 消息 / 用户 / 上下文 | 概述 · 原始内容（有来源时加 `来源`） | **同一套属性行**（状态 · Token · 开始时间 · 耗时 · 来源 · 层级 · ID）+ 可折叠 `预览` / `请求计时` |

- 属性行只有一份实现（`MetaItem`）：工具与消息不再各画一张 `dl`，字段间距、红/琥珀色调、复制按钮位置完全一致。
- 失败调用：行内跟原生一样显示 `→ Error: …`（等宽 10.5px、全红、单行截断），**不再给整行铺粉底**（原生只红描边/红文字）；右栏也不再自造 `失败` 横幅，改成原生的红色 payload（红字 + 错误底色）。

- 折叠块头带计数（`2 个键` / `5 行` / `1.2 KB`），折叠着也知道里面有多少；无内容的块整块不渲染。
- 树内搜索命中会**高亮**（键与值同样处理），命中行加 8% 琥珀底，工具条显示「N 处命中」。
- 参数与结果统一用可搜索 JSON 树（同一组件既有行内 `bare` 模式，也有「原始」页签的搜索工具条）；对象展开成节点，长字符串折叠可展开，每个分支可单独复制。
- 头部：一行主对象（工具是命令行首行，其他是正文首行），单行截断、悬浮显示全文；右侧 `⧉` 复制主对象、`⌖` 在列表中定位、`×` 关闭。
- 切换记录时若当前页签不存在，自动回到 `概述`（页签随记录类型变化）。

### 6.3 手势

- **拖拽分隔**：`col-resize`；1:1；clamp 420–720；松手 180ms 吸附到 420/520/640；双击复位 520（180ms）。
- **滚轮/触控板**：列表惯性原生；详情独立滚动，不联动。
- **双击行**：展开/收起该组（等价三角）。
- **拖选文本**：行内允许，拖拽不触发选中（mousedown 位移 >3px 取消 click）。

### 6.4 键盘

`/` 聚焦查询 · `↑↓` 建议 · `Enter` 采纳 · `Esc` 关闭建议→清空→失焦（三段） · `j/k` 或 `↑↓` 移行 · `Enter` 打开详情 · `Tab` 在查询/树/详情间循环 · `Cmd/Ctrl+Z` 撤销最近一次清空/折叠。

### 6.5 容错

- 一切可逆操作给 **undo toast**（4s）：清空查询、折叠全部、显示全部、批量收起。
- 无不可逆操作，因此不做二次确认弹窗（避免打断）；唯一例外：未来删除类功能。
- 空态：无记录 → 一行「无记录」+「加载更早」；过滤空 → 「无命中」+「清空筛选」；错误 → 行内错误条，不弹窗。
- 输入非法 token：不阻止输入，不弹窗；过滤时忽略并在建议区标因。

### 6.6 跳转逻辑

- 对话 → 轨迹 `focusRequest`：滚动到行、选中、打开详情、600ms 高亮衰减。
- 详情 chip 点击：`tool` chip → 用该工具作查询；`status` chip → 状态查询；两者都保留当前其它 token。
- 行内「显示」：清空过滤并保持滚动锚点，toast 可撤销。
